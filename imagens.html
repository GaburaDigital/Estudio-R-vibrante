    Como usar

    O caminho de cada imagem

    1. Produza o desenho com fundo branco e contorno escuro fechado. Pode haver branco dentro do desenho (olhos, dentes): ele é preservado.
    2. Salve o arquivo com o nome da palavra, por exemplo barata.png ou jacaré.jpg, e arraste vários de uma vez para a página. Se o nome não bater, a página pergunta qual é a palavra.
    3. A página remove o fundo, centraliza e ajusta para 512 x 512 px.
    4. Abra a palavra para conferir. Ajuste a tolerância se sobrar borda branca e clique nas áreas brancas presas para removê-las.
    5. Clique em Confirmar. Depois use Baixar pista para gerar o ZIP com os nomes certos.

    Dicas

    • Também dá para abrir uma palavra e colar a imagem com Ctrl+V (ou Cmd+V).
    • Imagens com pelo menos 800 px de lado dão um resultado melhor.
    • Se o contorno do desenho tiver falhas, o branco de dentro pode vazar junto com o fundo. Diminua a tolerância ou feche o contorno no desenho.
